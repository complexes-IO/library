# Complexes Institute of Technology · Element Library

An open library of industrial automation components (contactors, relays, sensors, valves, cylinders), each modelled once
from its governing standards, with its electrical and mechanical behaviour specified. Machines, control panels and lab rooms are
assembled from these components, and a digital twin simulates them from that behaviour.

Maintained by [CIT](https://complexes.org/), a US nonprofit. Released under the MIT License.

## What an element is

One folder, `lib/elements/<id>/`, holds everything the element is:

| file | what it holds |
|---|---|
| `element.py` | the geometry, built from the toolkit: every dimension a named figure |
| `spec.md` | what it is, every figure with its source (a standard's clause, a datasheet page, or "our own design" and why) |
| `ratings.csv` | its electrical and mechanical ratings |
| `behaviour.csv` | what it does at its terminals: pins, contacts, states |
| `parts.csv` | its sub-parts and how they move |
| `references/measure.md` | the measurement brief the figures were taken from |
| `out/` | the built model (`.glb`), the AutoCAD script, previews: regenerated by the build |

Element ids name the class, never a product: `class[-form][-size][-function]`, for example `contactor-9a-1no1nc`,
`prox-ind-m12-pnp-no`, `valve-sol-52-sr`. Every element belongs to CIT; no maker's name, part number or CAD file is
part of the library (see NOTICE.md).

## Try it

```
pip install numpy matplotlib
python lib/build.py contactor-9a-1no1nc      # build one element: geometry, checks, model
python lib/build.py                          # build everything and run every check (about 30 minutes)
python lib/build.py store                    # the elements the library still wants
```

Open any `out/*.glb` in a glTF viewer (Blender, Windows 3D Viewer, gltf-viewer.donmccurdy.com) to turn the part.

## How an element is checked

Before an element is released it passes eight stations, none of them ticked by hand: its identity and sources, static checks
(no overlaps, every port gendered, no unsourced figure), its behaviour, its ratings, the real tools (AutoCAD builds true solids
and a STEP, Blender checks the mesh, Godot checks it in the scene), an independent review, and an engineer's audit of every
figure the twin reports. A figure that is not on file is derived from its standard or waits for it; it is never guessed.

## Help build it

The [wanted issues](../../issues?q=is%3Aissue+is%3Aopen+label%3Awanted) list every element the machines still need.
Comment `/claim` on one and it is yours. `good first issue` marks the simplest. See CONTRIBUTING.md.

You can also help without writing code: check an element's figures against its datasheet, read a standard you own into a brief
(clause, page, figure), or photograph a real panel or machine so a drawing can be checked against the field.
