MACHINES OF A MACHINE-BUILDING FACTORY, FROM ELEMENTS (EM's list, 2026-11-08; the core's BOMs)
One line = one assembly BOM, as in machines-from-elements.txt. An id with no mark is in lib/inventory.csv already; (new) is an
element this list adds to the inventory; (own) = our own design (a frame, bed, table or guard we draw ourselves, not a product);
(tool) = a hand tool or instrument, an element in its own right, not an assembly. Every machine shares the same spine: a
structure (frame-welded, bed-cast, table-slotted), drives (motor-iec, vfd, servo), motion (ballscrew (new), linear-guide, rack-pinion (new)),
control (plc0, hmi-7in, pbs-6h-22) and safety (guard-interlock, light-curtain, op-estop-22-2nc, relay-safety-2ch-2no1nc); the department-specific
elements are the few at the end of each line. `python lib/build.py inventory` ranks elements by the systems of both lists, EM's
pins first (inventory.csv `pin`). First whole machine: press-hydraulic (EM 2026-11-08: what an engineer meets in the real world);
its 13 missing elements are pinned across the three lanes.
